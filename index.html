02
System Architecture

3개 모듈로 구성된 파이프라인

공고 수집(job_raw) → 위키 변환(job_core) → 커리어 매칭(job_career)의 단계로 구성

📡

job_raw

공공기관 채용공고를 일 단위로 자동 수집. 원문 마크다운과 JSON 아카이브를 함께 보관합니다.

수집 파이프라인
📂

job_core

수집된 raw 데이터를 NCS, 고용형태, 지역 등 8개 facet으로 분류하여 Obsidian 위키를 생성합니다.

위키 변환
🤖

job_career

OpenCode Go LLM으로 사용자 경력을 분석하고, Python 점수화로 최적 기관을 추천합니다.

AI 매칭
⏰ GitHub Actions cron 📝 Obsidian 호환 마크다운 🔗 Flask REST API 서버

04
job_raw · Collection Pipeline

공고 수집 자동화

한국고용정보원 공공 API를 통해 매일 신규 공고를 수집하고 원문을 보존합니다.

📥 수집 항목
• ncsCdNmLst (NCS 분류) • hireTypeNmLst (고용형태) • recrutSeNm (채용구분) • workRgnNmLst (근무지역) • aplyQlfcCn (응시자격) • prefCondCn (우대조건) • scrnprcdrMthdExpln (전형방법)
⚙️ 처리 흐름
1. API 호출 (최근 공고 기준) 2. 원문 frontmatter + 본문 마크다운 저장 3. JSON 아카이브 중복 보관 4. 만료 공고 정리 (cleanup) 파일명: {날짜}_{공고번호}_{기관명}_{제목}.md
📍 수집 소스: 한국고용정보원 · WorkNet 공공 API  |  ⏱ 실행: GitHub Actions (일 1회)

06
job_career · AI Matching Engine

2단계 커리어 매칭

LLM이 사용자 경력을 분석하고, Python이 점수화하여 최적의 기관을 추천합니다.

🔍 1단계: 초기 분석 (LLM)
  • • 사용자 경력 프로필 입력
  • • Facet_Index 기반 관련 분류 탐색
  • • 키워드 후보 + follow-up 질문 생성
  • • 모델: deepseek-v4-flash
📊 2단계: 최종 추천 (Python)
  • • 카테고리 히트 기반 점수 계산
  • • 50% 이상 매칭률 필터링
  • • 기관별 최종 매칭률 정렬
  • • UI에 카드 형태로 결과 표시
🖥️ Flask + HTML/CSS/JS 🔗 OpenCode Go API 📦 conda + pyproject.toml
